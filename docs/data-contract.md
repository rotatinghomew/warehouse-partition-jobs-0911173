# 离线作业时间语义

源分区的day属于地区业务日，不一定等于UTC自然日。事件原始时间必须含时区。地区日区间转换到UTC后可跨两个UTC日期。配置中的全国周口径为UTC周一零时至下周一零时；地区日汇总保留本地日期，全国周从统一时间边界选择来源，不把同名day直接拼接。

源分区修订表示同一地区业务日的一份完整更正，不与前版逐行叠加。现有显式日周运行API用输入参数指定计算，run_week检查调用者提供的日期范围；这不等于已经实现自动分区依赖或并行执行者协调。历史已命名发布不改写；日常消费者读取的当前完整发布可以向前推进。

地区业务日配置保存在calendar.json。输入记录可保留occurred时间以定位跨UTC周边界的活动，人数总量不能在未掌握事件时间时任意按小时比例切分。
